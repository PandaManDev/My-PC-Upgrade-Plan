# Panda's PC Upgrade Wishlist

A responsive, single-file wishlist website for tracking PC parts, prices, purchase progress, and an upgrade budget.

## Features

- Responsive dark-purple gaming design
- Current wishlist: Timetec 16GB DDR3/DDR3L SODIMM RAM, Crucial BX500 1TB SATA SSD, WD My Passport 2TB HDD, RK ROYAL KLUDGE R65 keyboard, and BENFEI DisplayPort-to-HDMI adapter
- Editable estimated prices and automatic totals
- Mark parts as purchased and track completion progress
- Filter by category and purchase status
- Set a budget and track remaining cost
- Export wishlist data as JSON
- Saves prices, purchases, and budget in the browser's local storage
- No build step or external JavaScript dependencies

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. After GitHub Pages finishes publishing, open the URL shown in the Pages settings.

The wishlist is client-side only. Saved prices and purchase checkmarks are stored separately in each browser and are not automatically synchronized between devices.

## Compatibility reminder

Before buying RAM or storage, confirm compatibility with your exact PC model and available slots/ports. In particular, verify RAM type, supported capacity, and drive form factor/interface before ordering.
