### How to Sign In

1. Open the Inbox Admin Panel.
2. Sign in using the email and password for your existing Supabase Auth account.
3. The account must have administrator access configured on the backend.

### Troubleshooting Admin Access

If you cannot sign in or conversations do not load:

1. Confirm the credentials are correct for your existing Supabase Auth account.
2. Verify the Supabase `CHAT_ADMIN_EMAIL` secret exactly matches the administrator account email.
3. Verify that the `pup-api` Supabase Edge Function is deployed and working.
4. Check the Supabase Edge Function logs for errors.
